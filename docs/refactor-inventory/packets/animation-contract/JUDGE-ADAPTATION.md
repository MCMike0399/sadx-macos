# Animation judge binding adaptation

The six original verifiers, original probes, original fixture vectors and frozen
Sonic unit/probe remain byte-identical. No tolerance, expected value, cohort, seed,
FP mask, old raw corpus or holdout is changed.

The separate judge commit binds the inherited probe targets and narrow source-only
builder to the new reference adapter translation units. Header mutations use private
include overlays. `migration_faults.py` names the same thirteen semantic faults:
four initializer faults, eight motion/blend faults and imported Gamma unavailable
to null. Ordering faults move the original publication/free rather than adding a
duplicate. The final initializer fault counts remain 8,402 / 8,404 / 193 / 8,337;
blend stored mismatch counts remain 24,888 / 1,404 / 302. Compile failure never
counts as caught. The initial anchor experiment remains local history and is not
the final receipt.

Gamma unit edits change field access to the plain type and explicitly assert all
three statuses. Unavailable reasons are compared as well. The complete 91-row
scalar/status/reason output remains byte-identical to the before-Source stream.

Three additional probes use plain native data under the frozen stock C ABI and
input vectors. Their source-only libraries contain no guest translation unit.
Only probe-side diagnostic normalization includes the reference phase mapping.
Complete outputs, including every FP flag and failure prefix, equal the frozen
103 / 16,440 / 7,944-case streams. The compatibility constant argument remains in
the frozen C ABI; shared arithmetic now uses the three verified source literals.
Arbitrarily substituted compiler constants are outside the pinned original-source
contract. The native API has no constant-pool transport.

The new publication unit compares every read and field publication against the
original instruction-hook stream, independently of the content recipe. It checks
147 source-zero BSS rows and 150 native retained-prefix cases from the same old
fully known seed/export-size cohort. A separate compiled transition/speed store
swap preserves final row values and is rejected at event 3. That is additional
qualification, separate from the thirteen inherited fault intents.

`run_units.py` builds the seven inherited units directly from Source. A private
copy of the frozen Sonic unit changes only the final animation fixture's types
and runtime binding to exercise the actual native Sonic updater route; expected
assertions and inputs are unchanged. The frozen registered unit is never edited,
and its observation include is applied to its own TU only.

The content emitter now emits the maintained typed header. It accepts the retained
statement ledger, verifies the original executable/body hashes, and reproduces the
current header byte-for-byte. The missing successful Ghidra producer dossier is
still missing; the retained error response is not promoted into evidence.

No global judge manifest refresh is performed. All 948 inherited protected paths
and all 53 raw binaries are present; old Make/registration hashes deliberately
change for binding/discovery. Root must review and seal a parent-preserving union
of the new protected inputs, including imported before-Source tools. Root also
owns constexpr-table lineage/review, inventory reconciliation and final gate.
The before-Source `verify_packet.py` remains unchanged and intentionally verifies
the untouched foundation checkout, not a migrated Source tree.
