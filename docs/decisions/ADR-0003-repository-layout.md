# ADR-0003: Repository layout, manifests and generated status

Date: 2026-10-12. Status: accepted.

## Context

`rea/sadx-native` had 243 sources, 208 tests and 110 tools in three flat directories,
a 480-line Makefile that needed four hand edits per module, and documentation kept as a
hand-edited status section plus a 197 KB journal.

## Decision

* New public repository `sadx-macos` (MIT for the port; third-party keeps its licences;
  the mod loader source is a GPL submodule under `reference/`, not vendored).
* `src/<area>/` by layer (`docs/ARCHITECTURE.md`); tests split into unit/probes/fixtures/python;
  oracles under `tools/oracles`.
* Build discovery by wildcard; the two things that need arguments (unit-test invocations,
  oracle commands) live in `manifest.tsv` files, from which `tools/gen_make.py` generates
  `build/*.mk`.
* `docs/STATUS.md` is generated by `tools/gen_status.py` from the latest gate record and
  the survey; `docs/ROADMAP.md` is the plan; `AGENTS.md` the rules; `docs/HANDOFF.md` the
  journal (append-only).
* `game/` and the large reference material are git-ignored; `tools/check_repo_hygiene.py`
  fails the gate on tracked binaries or files over 2 MB.
* Commits are allowed on this repository (Conventional Commits, no attribution lines);
  pushes only when the user asks.
