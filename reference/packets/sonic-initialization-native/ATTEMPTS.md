# Retained qualification corrections

Initial build attempts found a temporary animation::View passed to a non-const
reference, a misplaced generated decoder brace and a wrong CharacterTextureViews
constructor call. These were corrected before qualification. SDL3/libusb were
copied and dereferenced locally; builds always used max -j2 and the SDL header -o.

The first reentry witness reset Metal during a second Sonic archive rather than
the Metal archive. Its failed loaded[8] assertion was retained in local logs;
the lower callback now changes it at the actual Metal archive identity. The
missing-archive witness initially forgot the preexisting PInitialize auxiliary
task in list 2; it now asserts that exact retained task, rather than an empty list.

The old disconnected Metal graph reaches the second PSetMotion's unavailable
blend pose. Early expectations of either active welding or first-motion failure
were rejected by actual table/mode/callback observations. The graph input was not
changed. Source setup/weld order and both original model cohorts remain intact.

Fault harness setup rejected a wrong index mutation that compiled to an unused
parameter, a common-motion fault accidentally routed to the common-link judge,
and a wrong-mask mutation that left a constexpr unused. Equivalent compiled
mutations now use the input, route to initialization, and change the mask value.
No compilation failure is counted as a killed behavior fault.

The first profile invocation inspected an empty report directory and is not
qualification. Final profile evidence covers four declared ranges. Fresh-save
app timing is compared to the exact accepted Main binary with another private
fresh save, rather than assuming Main's retained save reaches the same frame.

The final audit caught a formatter-wrapped STUB annotation. Its comment was
shortened, all five source checks rerun successfully, and header dependencies
rebuilt the callbacks/tests. A nonzero primary-status reentry case now explicitly
stops before the remaining live Metal sound branch, rather than naming a later
attachment boundary. No intervening tail store or callee is claimed skipped.
