# Source-native binary64 CRT atan2

Frozen native owner: `sadx-native/src/crt_atan2.hpp/.cpp`, unit test `tests/crt_atan2.cpp`, native observation probe `tests/native_crt_atan2_probe.cpp`, and verifier `tools/verify_original_crt_atan2.py`. Parent owns production build integration. No shared CRT headers, Makefile, shared archive, game bytes or controller state were changed by this task.

## Exact source identity and contract

Source executable SHA-256 is `6b0937caa0151287c182fcd8cd02b89ea464bd33a13a081c1220fa791f24cd74`. Retained REA evidence `_reference/sadx/mesh-math-dependencies/crt-entry-645270.json` has EvidenceID `ev_13e718505384cd29c18410fa802007b12c410fc2b78e750e6feceea4d841920c`. The exact source bytes were independently disassembled using Xcode's `llvm-objdump`; no new Hopper session was opened.

Entry `0x645270` loads descriptor `0x2bcc170` and jumps to actual cdecl two-argument owner `0x64b3a4`. Descriptor bytes begin `056174616e3200000000000000021000`: name **atan2**, two arguments at +0xd, operation identity **16** at +0xe. The first formal binary64 argument is **y**, second **x**. The source loads y, then x, so FPATAN sees ST1=y, ST0=x. Actual query `0x453820` passes chosen-normal.x as formal y and chosen-normal.y as formal x. Host mathematical convention must not silently swap that call.

`crt_atan2_binary64(y,x,runtime,fp[,trace])` requires caller-selected X87Context and an explicit CrtAtan2Runtime. The runtime's optional matherr_control is the observed/selected word at `0x3c837a8`; BSS/file zero is not proof of its initialized value. Its handler is deliberately separate from the single-argument asin contract. The request preserves descriptor, operation16, error code, both original argument bit patterns, saved CW, final spill and the earlier scratch write. No source handler is fabricated or assumed to return the pending result.

## Recovered source behavior

The source loader `0x64b556` differs from shared `0x648bd5`. Finite doubles use actual FLD64 semantics. Special values are built as canonical ext80 and loaded without prematurely quieting signaling NaNs; their high significand word uses SHLD by11, but the low word copies the original low32 **without a shift**. That observed source detail changes NaN payloads. The existing generic CRT argument loader was therefore not incorrectly reused.

After both loads, the source saves incoming CW and installs **0x133f** for descriptor operation16. The actual 16-way classification table at `0x2bcc180` selects finite/zero/NaN/infinity routes independently for both arguments. Ordinary finite nonzero inputs execute absolute-value FPATAN followed by source quadrant subtraction (pi minus the positive result for negative x) and y-sign application. Zero/axis routes use source FLDZ, FLDPI or the exact retained extended pi/2 constant. Signed zero is preserved, including signed-zero pairs. Both infinities select source negative indefinite/error1 rather than a host atan2 infinity shortcut. NaN routes retain their source quiet-bit tests, operand ordering and error1/error7 identities.

All arithmetic uses X87Context and the explicitly named native `fpatan_bochs_p5_p6` model. There is no host atan2, host long double or x86 game emulation in production. An optional trace observes the genuine extended intermediate at `0x64b2ad`; it never selects or replaces arithmetic.

At `0x64b3de` the source writes the argument-copy flag at `0x3c83968` to zero. Unknown matherr policy stops at `0x64b3e5`, preserving partial extended result and CW0x133f. Nonzero policy bypasses the scratch store and dispatcher, then restores incoming CW. Policy0 performs FST64 to scratch `0x3c83960` without reloading/pop. Normal-body error marker -2 selects underflow code4 when that scratch's exponent is zero; the source scales the extended result by2^1536 before its final spill. That bounded finite atan2 scaling is modeled as an exact PC64 extended power-of-two product, not a universal FSCALE implementation. Source threshold/multiply order is retained. Incoming unmasked precision plus sticky PE selects error8; this owner's test uses the actual **clear** incoming mask bit, not asin's other return path.

Actual `0x64b518` calls `0x64dacb` after copying both original stack arguments and FSTP64 of the final result. Missing/unavailable handler stops there with pending spill, code, scratch write and current CW preserved. An explicitly supplied handler owns real dispatcher side effects/errno/matherr policy. On success, source FLD64 reload precedes incoming CW restoration. A waiting unmasked exception after restore is explicitly tagged at `0x64b443`, with the restored CW and sticky flags retained; it does not invent a successful value or mask/roll back the context.

Scratch/argument-copy fields describe source writes, not a claim about final shared global state after arbitrary reentrant callbacks. A future shared runtime owner must apply those writes in source order before dispatcher invocation, and must not replay stale writes after callbacks.

## Verification and what it establishes

Apple clang **21.0.0 (clang-2100.3.34.2)** compiled this owner as native arm64 C++17 using `-Wall -Wextra -Werror -ffp-contract=off -fno-fast-math`. Optimized and UBSan owner tests passed all12 PC/RC masked profiles, signed-zero/quadrant and special routes, exact special-loader payload, unknown policy, scaled underflow scratch/spill distinction, both-argument handler identity, unavailable handler and unmasked precision/return boundaries. Unit callbacks are labeled test fixtures, not real Windows handlers. The linked shared/vendor archive was not rebuilt or sanitizer-instrumented by this task.

The private comparison report `_reference/sadx/original-crt-atan2-comparison.json` records **28,416 completely unmodified source cases** across12 masked control words, explicit policy0/1, all classification combinations and deterministic random binary64 values. Original handler execution stops at its actual call; no source body, classifier or FPATAN is replaced. Source arguments are verified bit-for-bit in the real pending error record. Structural boundary, current/restored CW, error-code and argument-copy-flag mismatches are all **zero**.

That primary comparison remains explicitly **false** for full return-value/emulator agreement: **17,604** extended-return differences, **324** final-spill differences, **1,548** scratch-store differences, **19,776** FPATAN-intermediate differences and **25,224** flag differences are retained. Unicorn2.1.4's FPATAN goes through host binary64 (e.g. pi/4 significand ends `c000` while the selected Bochs result ends `c235`); its loss propagates through source quadrant arithmetic and extreme-ratio underflow. These observations do not prove the Bochs result matches modern Intel Ultra hardware.

A **separate 20,256-case suffix profile** supplies the native extended intermediate to ST0 only at source boundary `0x64b2ad`, after the real original prefix/FPATAN. It then executes the actual source quadrant/return/store/error instructions. This explicitly seeded profile has **zero** extended-return, spill, scratch, boundary, error, copy-flag or CW mismatches; all **20,256** flag differences remain recorded. Every primary nonflag difference is attributed only when the differing FPATAN intermediate is observed and the source scalar suffix then agrees. The report retains `returned_values_and_boundaries_match=false` and `full_emulator_match=false`; `local_control_and_suffix_matches=true` is the narrower result. CLI exit status fails unclassified nonflag or scalar-suffix differences, and is not a full-emulator pass claim.

Actual initialized Windows policy, source64dacb exception/errno/matherr handlers, stack/TOP/tag/C1 and deferred trap delivery, Intel Ultra physical FPATAN/status results, updated mod runtime and full-game collision behavior remain unverified. The parent's production-linked probe should rerun the verifier and record its own archive/executable identity; this private probe's identity is not a production archive claim.
