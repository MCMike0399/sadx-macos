# Gamma selection context

The reached N3b callback is `E102(task*)`, not a pose renderer. Root's normal-input
run reaches it after Question at frame 1382. This packet recovers mode 0 and the
mandatory common tail; other mode bodies stay explicit link-time boundaries.

The source dossiers and exact byte hashes are in `source-evidence.json`. Their
complete source bodies are 483430–4841ce, 7ca300–7cb55f and 7cb560–7cb66a,
inclusive. New.h names E102, E102Display and E102Destruct take precedence over
the older Gamma_Main/Display/Delete aliases. Assembly, rather than the
decompiler's reordered expressions, determines publication and fault order.

Canonical borrowed owners are TaskScheduler, Task.primary_state,
Task.motion_state and player_initialization::Registry/Player. PInitialize already
exists in player_startup.cpp. No second task pose, player physics, resource graph
or texture manager is introduced. CurrentView borrows the same current-primary
and current-player handles as Sonic; Root will migrate that shared owner under
the unchanged Sonic judges before product binding. Gamma does not write Super.

Entry captures the source motion pointer, old player and primary. Current
primary then old player are published before either predicate or PInitialize.
After PInitialize, the player is reloaded through the captured motion owner;
the published current-player slot remains old. The preview ID is primary.ID = 2.
Only source ID 1 enters the optional time-HUD factory branch.

Mode 0 calls PInitialize, binds the complete 91-row action table and request 0,
initializes three collision records, copies parameter height to collision row 0,
loads character textures 6, binds the weld list, stores actual callbacks, and
allocates 580 bytes of E102WK. Allocation failure is observable: the null free
work pointer and timer are stored before cursor initialization is called with
the source's interior cursor arguments. No early success or silent skip is valid.

Five live material table lookups modify row 1 material 6 and rows 5, 4, 3, 2
material 2 in that order. The last material is also published as the headlight
material. The shared mutable model/material graph must supply those records.
The common tail always calls PSetMotion, PJoinVertexes and E102Display, along
with the source's cursor, matrix, effects, shadow, collision and child-task calls.

Asset requirements at this boundary are Gamma action export 0 (Stand, not
selection export 2), all 91 table recipes, the real weld object rows 0 and 24–27,
the line colors, three CCL_INFO records, character texture
list 6, the five material rows above, and the real task callbacks. Root owns
importer work. The historical 78 declarations/constructed row 72/null export 61
are independently confirmed by executing the two original initializer bodies.

The four globals starting at the line-point publication form NJS_POINT3COL,
not an action/object animation descriptor. The source reference at 4c4d25 passes
that exact record to New.h's late_DrawLine3D (404310). Its fields are points,
colors, null texture and point count 2. Source 4c2e90 updates E102WK fan fields;
it is a named fan-update seam, not a cursor update. The two actual WIREMODEL
cursor records are initialized by 4c2e10 from templates 981ea0/981ec0.
The endpoint buffer is mutable BSS owned by Gamma State, not an imported action.
Source 4c4d00 writes its first X coordinate and 4c4d1d writes the next point's X
coordinate, exactly one NJS_POINT3 stride later. The line descriptor borrows
that one two-point buffer and the imported mutable color array.

STYLE models are player_initialization's canonical borrowed PrimaryView and the
plain link-time seams in game flow. New game code uses semantic views and named
free functions with an opaque Context. ExactFloat is reserved for the retained
Shadow return and source arithmetic/comparison premises in the new judge.
