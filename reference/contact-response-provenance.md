The43d8b0 sum is `(x²+z²)+y²`; the other four use `(x²+y²)+z²`. Source projection angle438410 uses the real native dot/acos/ftol owner with no host angle or fabricated callback. Native cosine uses the source quarter table and the same explicit X87Context.

Classification follows the actual FCOM/status-bit predicates, including unordered and equality cases. The43d180 helper counts selected class2 contacts; other helpers count eligible class8 contacts. A strictly closer distance replaces the initial1000.0 score. The final displacement clip occurs only when its source length is **strictly greater** than the selected stored distance. Normalization and component stores keep their original FLD-versus-memory operand order. Temporary normalized displacement remains local; final contact/world/vector stores mutate the actual shared owner in source order.

## Actual uninitialized/partial boundaries

The source initializes selected index to-1 and score to1000, and can count candidates without selecting a closer finite distance. In43cce0/43cf90/43d180/43d8b0, distance[-1] aliases classification[15]. That is a known source word only when contact15 was processed; otherwise native stops at the exact final comparison read unless the caller supplies an explicitly observed scratch word. In43d360, distance[-1] is a different uninitialized local, so classification[15] cannot substitute. No nearest index0 or zero distance is invented.

With16 source contacts, the classification-tail alias is interpreted as raw float bits, including its denormal encoding, rather than numerically casting the integer flag. An eventual response[-1] read remains unavailable. Counts above the existing16-response buffer fail at the first unavailable response read **after** retaining earlier effects, without a pre-clamp or fabricated extra payload. These rare source storage hazards are explicit limitations, not arbitrary geometry failures turned into success.

Selection scratch is marked uninitialized when the initial count read fails before local stores. normal_sum is present only for43cce0/43d360, where actual local zero stores exist. Projection failures retain their full native lower result and boundary. Unmasked arithmetic exceptions preserve the shared owner's partial stores/context under the existing X87Error contract; stack/TOP/C1 and deferred Windows trap timing are not claimed.
